# Digital Clock App

A frontend digital clock application that displays the current time across different time zones.

## Live Demo

🌐 [View Live App](https://my-react-app-two-liard.vercel.app/)

## Features

- Real-time digital clock
- Switch between CET, Pakistan, and USA time zones
- Dynamic time updates using JavaScript
- Simple interactive user interface
- Custom background and styling
- Fully frontend-based with no backend required

## Technologies

- HTML
- CSS
- JavaScript
- Vercel for deployment

## About the Project

This was one of my early frontend development projects, created to practice JavaScript, DOM manipulation, time handling, and CSS styling.

The application runs entirely in the browser and dynamically updates the displayed time based on the selected time zone.
